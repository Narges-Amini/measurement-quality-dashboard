# measurement-quality-dashboard
## Overview
A simple web dashboard for displaying measurement results
in a quality control and metrology context.

## Project Goal
The goal of this project is to practice HTML, CSS,
Git, GitHub and VS Code while working with a
metrology-related example.

## Technologies
- HTML5
- CSS3
- Git
- GitHub
- VS Code

## Measurement Data
The example data represents dimensional measurements of a hypothetical component.
Nominal dimension: 10.00 mm
Tolerance: ±0.10 mm
Acceptance range: 9.90 mm - 10.10 mm

## Features
- Measurement summary
- Pass/Fail status
- Measurement table
- Responsive layout
